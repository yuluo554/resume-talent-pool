## 合成数据纪律（脱敏审查白名单）

- **手机号**：仅 199 假号段——主号 `1990000xxxx`、换号 `1990005xxxx`（xxxx=人员序号 4 位），全部为虚构号码；正则扫描 `1[3-9]\d{9}` 命中者均属本白名单范围，不构成真实个人信息。
- **邮箱**：仅 `example.com` / `example.net` 保留域（RFC 2606），不可能指向真实邮箱。
- **人名/公司/院校**：全部虚构（姓名池见 generator_specs/names.json；如有雷同纯属巧合）。
- **证书/技能**：通用真实资质名称（CET、软考等），不关联任何个人。
- 生成器模块 docstring（`src/resume_talent_pool/evaluation/generator.py`）写明全部真值语义与复现纪律；truth.json schema 见 plan/05 §2.3。
