# 模拟赛题：简历解析与人才库管理桌面应用

> **性质**：自拟模拟赛题（体例对标研究生大赛揭榜赛道赛题说明）。**交付形式为 Windows 桌面应用程序**：PySide6 开发、PyInstaller 打包 exe、GitHub Release 附安装包，本地运行、无服务器。
> **目标产出**：GitHub 公开仓库 `resume-talent-pool`（独立品牌；与系列前五项目同方法论、代码不共享、业务互不提及）。
> **题目定稿日期**：2026-10-05

## 一、赛题介绍

2025 届全国普通高校毕业生规模预计达 1222 万人（教育部、人社部 2025 届就业创业工作会议，2024-11），叠加社招流动，简历处理量持续攀升。HR 侧真实痛点：简历散落在邮箱与聊天工具中无法沉淀复用；同一候选人的多版本简历在人才库中重复堆积、历史经历无法串联；检索筛选靠翻 Excel。商业招聘 SaaS（ATS/人才库类产品）闭源收费且数据在线上，**本地优先、可复现的开源桌面人才库工具在 GitHub 上是空白**（现有简历解析开源项目多为英文、且止步于解析不含库管理与归一）。

同时，《个人信息保护法》（2021-11-01 施行）对简历这类个人信息的收集、存储、使用提出明确合规要求——本题把**隐私合规做成产品功能**（本地存储、脱敏显示、一键清除），是差异化亮点。

本题要求开发一款简历解析与人才库管理桌面应用：简历批量导入解析、本地人才库管理与检索、**同一候选人多版本简历识别与合并**、JD 硬条件初筛、导出，全流程本地运行。

## 二、任务要求

### 1）简历批量导入与解析

- 输入：PDF / docx / txt 模拟简历，拖拽批量导入；
- 抽取：姓名、手机号、邮箱、学历学位、院校与专业、毕业时间、工作经历（公司/职位/起止时间）、技能标签、证书、期望职位；
- 输出统一中间表示（"候选人参数卡"：字段-值-置信度-证据{来源文件，原文摘录}），中文简历为主（规则优先解析，LLM 可选兜底）。

### 2）本地人才库管理

- SQLite 存储（含 FTS5 全文检索）；候选人列表/详情、标签体系（自定义技能/来源标签）、多维筛选（学历/工作年限/技能命中/更新时间）；
- 候选人时间线视图：同一人的多份简历按时间排列，展示经历演变。

### 3）同一候选人识别与合并（核心算法）

- 多版本简历实体归一：姓名+手机号/邮箱精确匹配 + 姓名模糊（同音/别名）+ 经历重叠度综合评分；
- 合并策略：保留最新参数卡、历史版本归档、冲突字段列表输出**待人工确认**（不硬判）；
- 评测指标：同一人识别准确率、误合并率（合成数据植入"同一人多版本"真值）。

### 4）JD 硬条件初筛（规则版）

- 输入职位要求（学历门槛、年限区间、必备技能关键词、排除项）→ 候选人逐条命中矩阵 + 简单匹配分排序；LLM 语义匹配为可选加分项（离线兜底必须可用）。

### 5）隐私合规设计（产品功能而非口号）

- 全本地存储、零上传；手机号/邮箱**脱敏显示开关**（默认脱敏）；"一键清除全部个人信息"；启动页展示 PIPL 合规说明与数据存储位置——把 2021-11-01 施行的《个人信息保护法》要求落成可演示功能。

### 6）内置评测基准（零 API 依赖）

- **合成简历生成器**（python-docx/reportlab，固定 seed）：按人群模板批量生成简历，**程序化植入已知关系**（同一人多版本、字段缺失、格式噪声、同名不同人）并输出真值 JSON；
- 指标：字段解析 P/R/F1（目标 ≥0.95）、同一人识别 P/R、误合并率 0；指标表写进 README。

## 三、提交材料

1. 桌面应用（PySide6），PyInstaller 打包 Windows exe；2. 核心代码框架（GitHub 公开仓库，含自评基准与测试）；3. 技术报告（解析方案、实体归一算法、合规设计）；4. 合成简历数据集与生成器（含真值）；5. GitHub Release：exe 安装包 + 演示 GIF/截图。

| 依据 | 内容 | 状态 |

| 《中华人民共和国个人信息保护法》 | 2021-08-20 通过、2021-11-01 施行；目的限定/最小必要原则直接约束简历处理 | ✅ 施行日期与原则条款已核对 |
| 教育部、人社部 2025 届就业创业工作会议 | 2025 届毕业生预计 1222 万人（同比+43万），2024-11-14 | ✅（央视新闻报道在案） |

- **需求真实**：毕业生规模创新高 + 简历沉淀/归一是招聘运营刚需；
- **开源空白**：英文简历解析器多，中文本地人才库闭环（解析→归一→库→初筛）无开源实现；
- **合规即亮点**：PIPL 落成可演示功能，区别于同类工具的纯功能堆叠。

## 六、边界与非目标（不防 scope 失控）

- **不做**：真实简历（全部合成，人名/手机号/邮箱虚构——合成手机号统一用 19900000000 段假号并在台账与脱敏审查白名单登记）；招聘网站爬取；背景调查；面试评价；**招聘决策建议（辅助筛选定位，非录用决策工具，报告带免责声明）**。
- **隐私红线**：本地 SQLite、零网络上传、默认脱敏显示、可一键清除。
- **品牌隔离**：不复制姊妹项目代码；文档不提建造/电力/医疗/招投标/食品/财务业务。
