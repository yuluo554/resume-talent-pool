## 2. 合成简历生成器详设（M1）

### 2.1 人群模板 × 简历格式

| 模板 | 特征 | 版本演进 |
|---|---|---|
| 应届生 | 学历学位突出、实习 1-2 段、校园经历、证书多 | v1 校招简历 → v2 毕业后（补社招首份工作） |
| 社招技术 | 3-8 年、技能栈 5-10 项、项目描述 | v1 → v2（跳槽/加技能/换手机号） |
| 社招职能 | 行政/财务/HR 类、证书（初级会计等） | v1 → v2 |

输出格式按 pdf:docx:txt ≈ 4:4:2（reportlab / python-docx / 模板文本），排版分"标签式/分节式"两套模板注入格式多样性。

### 2.2 程序化植入关系（真值核心）

| 关系 | 植入方式 | 占比 |
|---|---|---|
| 同一人多版本 | 同一虚拟人生成 2-3 份简历，时间推进：经历追加、技能增加；30% 换手机号、30% 改邮箱、学历不变 | ~60% 人有 2+ 版本 |
| 同名不同人 | 5 组同名（同音也含），phone/email/经历完全独立 | 5 组 |
| 字段缺失 | 按字段 10–30% 概率缺失（缺手机号/缺毕业时间等） | 均匀注入 |
| 格式噪声 | 伪空格、全角数字、分隔符变体、经历区块多行、CRLF | 覆盖 ~50% 文件 |

### 2.3 真值 JSON schema

```json
{
  "seed": 20261005,
  "persons": [
    {"person_id": "p001", "same_person_group": "g001",
     "resumes": [
       {"file": "p001_r01_v1.pdf", "truth_fields": {"name": "张三", "phone": "19900000001", "…": "…"},
        "truth_experiences": [{…}], "truth_skills": […]}
     ]}
  ],
  "relations": {"same_person_groups": [["p001", "p002"]], "homonym_groups": [["p010", "p011"]]}
}
```

真值语义一次定清：`truth_fields` 为该文件**应被解析出**的字段全集（生成器只写确定项；缺失字段不在真值中，解析器多解析出来按 FP 计入——防止解析器靠"蒙"刷分）；`same_person_group` 是归一评测的聚类真值。

**M1 落地定稿（2026-10-05，实现即合同，详见生成器模块 docstring 与 D-016）**：每份文件另带 `format/layout/noise/encoding` 元数据（供 M2 对照工程陷阱清单，不参与指标对账）；`truth_version=1`；person_id=一个虚拟人，`same_person_group` 与之一一对应，`relations.same_person_groups` 列出**全部**组（含单人组）——文件级聚类真值=文件→person→组；`relations.homonym_groups` 为 5 组同名/同音对（组内 phone/email/经历完全独立，同名搭档公司互斥注入）；`truth_certificates` 为证书标签集合（区块未渲染则空集）。

### 2.4 复现纪律

- 默认 seed `20261005`，CLI `--seed` 可换；生成结果（除文件内时间戳外）与真值在固定 seed 下**逐字节可复现**，M4 基准与 CI 依赖此性质。
- 生成器模块注释写清每类植入的真值语义（系列经验：真值语义返工代价极高）。

## 4. 风险与对策

| 风险 | 概率 | 对策 |
|---|---|---|
| pdfplumber 对生成 PDF 抽取偏差 | 中 | M1 就用 reportlab 产样例与解析器同源联调；生成器控制字体与布局 |
| FTS5 中文检索效果 | 中 | trigram 已确认可用（sqlite 3.34.0）；M3 实测不行则改 2-gram 预分词双写 |
| PySide6 对 Python 3.8 支持上限 | 低 | pin `<6.8`；若仍不兼容 → 升级 Python 底线（改 requires-python 需决策留档） |
| PyInstaller 体积/杀软误报 | 中 | onedir+zip；排除不必要模块；文档说明误报处理 |
| F1 门槛不达 | 中 | 解析器与生成器同源迭代（规则覆盖生成模板的每种格式）；M2 先 0.9 联调再冲 0.95 |
| 本机随机崩溃/环境坑 | 中 | `PYTHONDONTWRITEBYTECODE=1` 全程、测试分批 ≤50 项、单轮随机失败先重试（crash-loop-rescue 阶梯） |
| scope 失控（GUI 细节无底洞） | 中 | P0/P1/P2 分级 + 里程碑 DoD 收口；P2 项（LLM、时间线美化）明确可砍 |
